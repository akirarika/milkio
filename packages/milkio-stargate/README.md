# @milkio/stargate

Part of the [milkio](https://github.com/akirarika/milkio) monorepo.

## Install

```bash
pnpm add @milkio/stargate
```

## Development

This package lives in `packages/milkio-stargate` of the milkio workspace. Install the workspace dependencies from the repository root, then use the root scripts:

```bash
pnpm install
pnpm test
```

Documentation: [milkio.fun](https://milkio.fun)
